# Live Microphone Oscilloscope

A real-time microphone oscilloscope built with Python, PyQtGraph, and SoundDevice.

## Features

* Real-time microphone input visualization
* Smooth waveform updates
* Lightweight and fast
* Cross-platform support

## Technologies Used

* Python
* NumPy
* SoundDevice
* PyQtGraph
* PyQt5

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Screenshot

![Demo](screenshots/demo.png)

## How It Works

The application captures audio samples from the microphone using SoundDevice and continuously updates a waveform display using PyQtGraph.
